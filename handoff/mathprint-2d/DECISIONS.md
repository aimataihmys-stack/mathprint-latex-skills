# 위임 범위에 따른 적용 결정

## 근거와 미확인 사항

확인된 요구는 이 대화에서 합의한 **G4 제외, 전문적인 한국 수학 문제집용 2D 저작도구, 로컬 gf2/gratik 재사용, TikZ 연동 편집, 스킬을 GitHub에 올려 읽게 하기**입니다.

지정된 별도 Claude 웹 대화의 원문은 이 인계를 작성한 환경에서 조회되지 않았습니다. 따라서 아래 세 결정은 **그 대화에 적힌 세 요구사항을 전사하거나 승인한 결과가 아니라**, 이미 확인된 요구에 대한 작성자의 구현 판단입니다. 대상 세션 안에서 실제 세 항목을 읽을 수 있는 실행자는 원문과 아래 결정을 대조하고, 불일치가 있으면 사용자 지시를 우선합니다. 원문 확인 전 세 항목 완료로 보고하지 않습니다.

## 결정 1 — 기능 범위는 2D 출판 저작에 집중

G4를 제외합니다. 그 대신 점·선·도형 관계, 한글·수식 라벨, 점선/선폭/치수/마크, 함수 정의역·개폐점·음영, 저장·실크기 출력을 우선합니다. 원본의 3D 확장은 참고로만 보존합니다. 특정 출판물의 스타일을 무조건 복제하거나 기존 관찰 수치를 공인 표준으로 삼지 않습니다.

수용 기준: 기존 도형의 보조선만 점선으로 바꾸고 점 이름·라벨을 수정해도 나머지 원문과 작도 관계가 유지되어야 합니다.

## 결정 2 — 실제 TeX 조판을 유지하되 편집 모델과 실행 경계를 분리

gf2/tkz-euclide는 기하 출력, gratik/PGFplots는 그래프 출력의 참고 기반으로 유지합니다. 자체 도형 문서·안정적인 ID·명령 이력·원문 바인딩을 중심에 둡니다. 브라우저 미리보기를 실제 TeX 출력과 동일하다고 주장하지 않습니다. 일반 TikZ 전체 양방향 지원을 약속하지 않고 지원 문법을 좁혀 검증합니다.

첫 개발 경로는 로컬 우선입니다. 공개된 임의 TeX 컴파일 서버는 만들지 않습니다. 기존 렌더러는 개발자 소유의 신뢰한 예제 전용이며, 제품용 렌더 실행부에는 별도 권한·네트워크·자원 제한과 검증이 필요합니다.

수용 기준: 원문 무변경 왕복, 점/라벨 수정 최소 diff, TeX 객체 ID 대응, 오래된 조판 폐기, 60mm 출력과 저장·재열기를 실제로 검사해야 합니다.

## 결정 3 — 원본은 보존하고 별도 브랜치에 읽기 가능한 스킬 묶음을 전달

처음에는 원본 원격 `hotdeli88-pixel/geo`의 별도 인계 브랜치를 준비했으나, 로컬 Git 계정 불일치와 GitHub 앱의 쓰기 권한 부족으로 각각 403 거부를 확인했습니다. 원본 원격은 바꾸지 않고 `aimataihmys-stack/mathprint-latex-skills`의 `main`에 선별 스킬만 게시합니다. 독립 배포 저장소는 과거 geo Git 이력·교재 코퍼스·PDF·개인 설정을 가져오지 않습니다. 원본의 다른 미커밋 작업을 stage하거나 모두 push하지 않습니다.

gf2/gratik 문서는 로컬 최신본을 가져오고, 누락된 렌더러는 정상 일반 파일로 포함합니다. 새 `mathprint-2d` 진입점과 정정·한계 문서를 먼저 읽게 합니다. 원본 연구 노트의 로컬 경로나 미포함 PDF는 클라우드 필수 의존성이 아닙니다. 인증정보·폰트·개인 설정·교재 코퍼스·학생 데이터는 추가하지 않습니다. 다른 세션을 자동 재시작하거나 메시지를 보냈다고 주장하지 않습니다.

수용 기준: 전용 저장소의 원격 커밋이 존재하고, 게시된 스킬과 manifest가 다시 읽히며, 선별 원본 파일의 해시·git 상태·index가 작업 전후 같아야 합니다.
