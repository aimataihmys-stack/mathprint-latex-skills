# 기존 스킬을 제품에 적용할 때의 정정·한계

원본 문서 자체의 역사를 지우지 않고, 이번 2D 제품에서는 아래와 같이 해석합니다.

| 원본 항목 | 이번 적용 기준 |
|---|---|
| gf2의 꼭짓점 배치 설명에서 CW/CCW가 상충 | y축 위 방향의 좌표계에서 signed area/cross product로 방향을 계산합니다. 위-A·왼아래-B·오른아래-C 순서는 CCW입니다. |
| 꼭짓점별 고정 angle 인자 순서표 | 내각/외각·반사각·부호를 실제 벡터로 검사합니다. 이름이나 표 하나로 각 방향을 강제하지 않습니다. |
| 초기 research DESIGN-SYSTEM과 최신 스킬의 선폭·크기 수치 차이 | 사용자 지정 > MathPrint 적용 프로필 > 해당 프리셋의 검증된 설정 순입니다. 오래된 테이블을 합쳐 하나의 공인 규격처럼 만들지 않습니다. |
| 연구 노트의 100%, 표본·측정 횟수, 동결·표준 표현 | 재검증되지 않은 원본의 관찰/주장입니다. 이번 제품의 합격률·보편 표준·미래 문서의 실제 발행 사실로 인용하지 않습니다. |
| `fill=white`로 라벨 아래 도형·곡선을 가리는 예시 | 라벨을 빈 공간으로 이동합니다. 치수호의 의도적인 끊김은 경로 gap으로 구현하고 실제 도형의 선을 지우지 않습니다. 열린점의 기호 표현과 라벨 마스킹은 구분합니다. |
| 그래프를 짧은 호로 그리는 프리셋과 보이는 범위를 모두 그리는 규칙의 상충 | 수학적 정의역과 표시 범위를 분리하고 사용자가 선택한 표현을 기록합니다. 불연속을 연결하거나 조건을 바꾸지 않습니다. |
| 특정 학년에서 특정 차트만 허용하는 관찰 | 그 참고 자료에 대한 프리셋 관찰일 뿐, 통계 도판 제품 기능 전체를 금지하는 규칙이 아닙니다. |
| gf2의 3D 확장과 연구의 G 절 | G4 제외 지시에 따라 구현하지 않습니다. |

## 검증 스크립트의 한계

`verify-overlap.py`는 PDF 텍스트 bbox 주변의 픽셀과 제한된 TeX 마크 구문을 검사하는 휴리스틱입니다. 반복 글자의 객체 ID 연결, 모든 겹침, 모든 수학 조건을 입증하지 않습니다. `--no-compile`도 PDF가 없으면 컴파일할 수 있으므로 불신 입력에 실행하지 않습니다.

`verify-gratik.py`는 정규식 기반 정적 검사이고 간단한 산술 평가에 `eval`을 사용합니다. 문자 제한이 있다고 자원 고갈까지 안전한 것은 아닙니다. 도메인 끝값 0을 `or`로 처리하는 부분 등 경계값은 제품 엔진에 그대로 복사하지 말고 별도 시험합니다. 이 스크립트의 경고 없음은 함수 수학·보안·출판 품질의 증명이 아닙니다.

기존 `render-tex.py`는 timeout·운영체제 격리·파일 접근 정책을 갖춘 공개 컴파일 서비스가 아닙니다. 공용/스킬 경로의 세 사본은 호환성을 위해 같은 원본을 전달한 것입니다. 새 `smoke-render.py`는 고정된 신뢰 예제만 실행하고 no-shell-escape와 시간 상한을 더하지만, 이것도 완전한 샌드박스는 아닙니다.

## 자료와 라이선스 경계

새 커밋에는 스킬 텍스트·코드·작은 자체 예제와 인계 문서만 추가합니다. 교재 스캔·PDF·코퍼스·폰트 파일·로컬 설정을 새로 게시하지 않습니다. 원본 저장소에 이미 존재하는 과거 자료를 새로 심사하거나 재라이선스한 것으로 해석하지 않습니다.

문서에 언급된 패키지·폰트·라이브러리의 이름은 번들 제공을 뜻하지 않습니다. 실제 제품 배포 시 채택 버전의 라이선스·고지·폰트 임베딩 조건을 별도로 확인합니다. `references/ingested-pgfplots-kias.md`의 Windows 개인 경로 두 곳은 비식별 참조로 바꾸었고 원본/게시본 해시는 manifest에 남깁니다.

## 재현성

`source-manifest.json`에는 로컬 최신 미커밋 내용을 포함한 선별 원본 해시와 게시본 해시가 있습니다. 해당 원본 commit ID만으로 미커밋 최신 내용을 재현할 수는 없습니다. 실제 게시 commit SHA와 manifest를 함께 사용합니다. 원본 패키지 문서의 과거 테스트 횟수는 이번 인계 테스트 결과와 합산하지 않습니다.
