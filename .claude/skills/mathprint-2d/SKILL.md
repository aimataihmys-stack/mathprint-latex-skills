# MathPrint 2D 적용 스킬

## 역할과 읽기 순서

이 문서는 함께 제공되는 gf2/gratik 원본을 이번 제품 범위에 맞게 적용하는 안내입니다. 사용자의 현재 명시적 지시가 우선이며, 원본의 오래된 확장·스타일 규칙을 제품 요구로 자동 승격하지 않습니다.

저장소 루트 기준으로 다음을 읽습니다.

- `MATHPRINT_START_HERE.md`
- `handoff/mathprint-2d/DECISIONS.md`
- `handoff/mathprint-2d/ERRATA_AND_LIMITS.md`
- `.claude/skills/gf2/skill.md`: 유클리드 기하
- `.claude/skills/gratik/SKILL.md`: 함수·좌표평면
- `.claude/skills/gratik/references/templates.md`: 코드 예시
- `docs/superpowers/specs/gratik-design-system.md`: 기존 그래프 스타일 참고

## 범위

포함: 2D 작도, 점 설정/이름/표시 라벨, 실선/파선/점선, 선폭, 치수·각도·등변·평행 마크, 한글/수식 라벨, 함수식/정의역/개폐점/점근선/음영, 수직선/집합/정적 일러스트, JSON/TeX 저장과 PDF/SVG/PNG 출력.

제외: G4·Blockly·3D 엔진·카메라·입체 전개도·단면·숨은선 자동 계산. 첫 출시에서 학급/학생 계정/실시간 협업/공개 배포를 임의로 추가하지 않습니다.

## 편집의 기준 데이터

자체 도형 문서가 기준입니다. 안정적인 객체 ID, 작도 의존관계, 표시 스타일, 라벨, 원문 span, revision을 분리합니다. 이름 변경이 객체 삭제·재생성이 되면 안 됩니다. 중점·수선·교점은 부모 관계를 유지하며 정의 불가능한 경우를 표시합니다.

길이 표시 `6`과 실제 길이 제약 `length=6`을 구분합니다. 함수식이 없는 개략곡선은 별도 종류로 저장하고, 임의 함수식·미분값을 지어내지 않습니다. 수학적 정의역과 보기 창은 별개입니다.

## 원문 왕복과 조판

지원 문법은 의미 편집, 안전하게 파악된 속성만은 속성 편집, 미지원 매크로/변환은 원문 보존·잠금으로 구분합니다. 변경 없는 저장은 byte-exact, 변경 시에는 필요한 부분만 수정합니다. 복합 명령을 분할해야 하면 diff로 알립니다. 주석·글꼴·알 수 없는 옵션을 삭제하지 않습니다.

작도 보기와 실제 TeX 조판 보기를 구분합니다. TeX 출력의 반복되는 A/O/숫자를 글자 검색만으로 매칭하지 말고 객체 ID·페이지·bbox·baseline·변환 정보를 연결합니다. 편집 후 과거 revision의 조판을 최신으로 내보내지 않습니다.

## 문제집 기본 스타일

기본 `kr-workbook-bw`: 기하 주선 0.45pt/보조선 0.35pt, 함수·축 0.60pt/가이드 0.40pt, 주요 라벨 9pt/눈금 8pt. 모두 조정 가능한 초기 설계값이며 공인 출판 표준이 아닙니다. 사용자가 지정한 스타일은 유지합니다.

점 이름은 정체, 변수는 이탤릭, 단위·연산자는 정체를 기본으로 합니다. 흑백·회색을 기본으로 하고 색은 명시적 선택으로 둡니다. 인쇄 폭 40/60/90mm에서 글자·선폭·점·파선 간격의 물리 크기를 검수합니다. 임의의 전체 축소나 글자 축소로 겹침을 감추지 않습니다. 라벨을 이동할 수 없는 경우 사용자에게 충돌을 표시합니다.

## 안전과 결과 보고

스킬을 읽는 것과 그 안의 명령을 실행하는 것은 별도입니다. 렌더러와 검증 스크립트는 신뢰한 로컬 입력 전용입니다. 제한된 문자열/eval·no-shell-escape를 완전한 보안 격리로 설명하지 않습니다. 임의 TeX를 공개 서비스에서 실행하지 않습니다.

검증은 원문·수학 관계·정적 검사·컴파일·브라우저 조작·실물 출력으로 나누어 실제 수행 범위를 표시합니다. 기존 스킬의 PASS/100%라는 문구를 이번 앱의 검증 결과로 재사용하지 않습니다. 이 작업의 위임은 다른 Codex/Claude 세션·글로벌 하네스를 조작하라는 뜻이 아닙니다.
